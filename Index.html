Luva

Roblox obby with persistent progress

An obstacle-course (obby) game where a player's coins, wins, and furthest checkpoint are saved server-side, so progress survives between sessions. Built the full loop of systems that make an obby feel alive: things that help you, things that hurt you, and a way to keep score of both.

  • DataStore-backed save/load per player, with retry-safe writes on leave and server shutdown
  • Checkpoint system that respawns players at their furthest point reached
  • Collectible coins with pickup cooldown and respawn timing
  • Kill bricks with per-player debounce to prevent repeat damage
  • Speed pads that temporarily boost movement, then decay back to normal
  • Finish line that awards coins and wins, then resets the run
  • Live HUD reading each player's leaderstats in real time
